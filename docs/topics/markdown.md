# آموزش کامل Markdown

### از صفر تا صد برای نوشتن مقالات

سلام! این راهنما برای این نوشته شده که تو بتونی به راحتی هر نوع متنی، از یک یادداشت ساده گرفته تا یک مقاله کامل رو با استفاده از Markdown بنویسی. Markdown یک زبان نشانه‌گذاری خیلی ساده‌ست که بهت اجازه می‌ده بدون نیاز به نرم‌افزارهای پیچیده مثل Word، متن‌های زیبا و ساختاریافته بنویسی.

مزیت بزرگش اینه که خیلی راحت به فرمت‌های دیگه مثل HTML تبدیل می‌شه و پلتفرم‌هایی مثل گیت‌هاب، وبلاگ‌ها و خیلی از ابزارهای دیگه ازش پشتیبانی می‌کنن.

بزن بریم شروع کنیم!

## بخش اول: اصول اولیه و ضروری

اینجا چیزهایی رو یاد می‌گیری که برای ۹۰٪ کارهات کافیه.

### سرتیترها (Headings)

برای مشخص کردن عنوان‌ها و بخش‌های مختلف متن از `#` استفاده می‌کنی. تعداد `#` سطح سرتیتر رو مشخص می‌کنه.

```markdown
# این یک سرتیتر سطح ۱ است (عنوان اصلی مقاله)
## این یک سرتیتر سطح ۲ است (بخش اصلی)
### این یک سرتیتر سطح ۳ است (زیربخش)
#### این یک سرتیتر سطح ۴ است
##### و همینطور تا سطح ۶
###### این هم سطح ۶
```

**خروجی:**
# این یک سرتیتر سطح ۱ است (عنوان اصلی مقاله)
## این یک سرتیتر سطح ۲ است (بخش اصلی)
### این یک سرتیتر سطح ۳ است (زیربخش)
#### این یک سرتیتر سطح ۴ است
##### و همینطور تا سطح ۶
###### این هم سطح ۶

---

### استایل متن (Text Styles)

می‌تونی متن رو به سادگی **پررنگ**، *کج* یا ~~خط‌خورده~~ کنی.

```markdown
*این متن کج (Italic) است.*
_این هم کج است._

**این متن پررنگ (Bold) است.**
__این هم پررنگ است.__

***این متن هم پررنگ و هم کج است.***
**_این هم جواب می‌ده._**

~~این متن خط خورده است.~~
```

**خروجی:**

*این متن کج (Italic) است.*
_این هم کج است._

**این متن پررنگ (Bold) است.**
__این هم پررنگ است.__

***این متن هم پررنگ و هم کج است.***
**_این هم جواب می‌ده._**

~~این متن خط خورده است.~~

---

### نقل‌قول (Blockquotes)

اگه بخوای یک متنی رو از جایی نقل کنی یا بهش تاکید خاصی بدی، از `>` استفاده کن.

```markdown
> این یک نقل‌قول است. تمام متنی که بعد از این علامت بیاید، به صورت نقل‌قول نمایش داده می‌شود.
>
> > می‌تونی نقل‌قول‌های تودرتو هم داشته باشی.
```

**خروجی:**
> این یک نقل‌قول است. تمام متنی که بعد از این علامت بیاید، به صورت نقل‌قول نمایش داده می‌شود.
>
> > می‌تونی نقل‌قول‌های تودرتو هم داشته باشی.

## بخش دوم: لیست‌ها

لیست‌ها برای مرتب کردن اطلاعات عالی هستن.

### لیست نامرتب (Unordered List)

با استفاده از `*`، `-` یا `+` می‌تونی لیست نامرتب بسازی.

```markdown
* آیتم اول
* آیتم دوم
  * زیرآیتم اول (با یک فاصله یا Tab)
  * زیرآیتم دوم
- آیتم سوم
```

**خروجی:**
* آیتم اول
* آیتم دوم
  * زیرآیتم اول (با یک فاصله یا Tab)
  * زیرآیتم دوم
- آیتم سوم

### لیست مرتب (Ordered List)

برای لیست‌های شماره‌دار، از اعداد استفاده کن. نکته جالب اینه که لازم نیست شماره‌ها رو درست وارد کنی، مارک‌داون خودش درستش می‌کنه!

```markdown
1. آیتم اول
2. آیتم دوم
3. آیتم سوم
   1. زیرآیتم اول
   2. زیرآیتم دوم
```

**خروجی:**
1. آیتم اول
2. آیتم دوم
3. آیتم سوم
   1. زیرآیتم اول
   2. زیرآیتم دوم

## بخش سوم: لینک‌ها و تصاویر

هیچ مقاله‌ای بدون لینک و تصویر کامل نیست.

### لینک‌ها (Links)

فرمت کلی لینک به این صورته: `[متن لینک](آدرس لینک)`

```markdown
برای جستجو می‌تونی از [گوگل](https://www.google.com) استفاده کنی.
یا می‌تونی به [صفحه گیت‌هاب من](https://github.com/your-username) سر بزنی.
```

**خروجی:**

برای جستجو می‌تونی از [گوگل](https://www.google.com) استفاده کنی.
یا می‌تونی به [صفحه گیت‌هاب من](https://github.com/your-username) سر بزنی.

### تصاویر (Images)

اضافه کردن تصویر خیلی شبیه به لینکه، فقط یک `!` اولش اضافه می‌شه.
فرمت: `![متن جایگزین تصویر](آدرس تصویر)`

متن جایگزین (Alt Text) برای زمانیه که تصویر لود نمی‌شه و برای دسترسی‌پذیری هم مهمه.

```markdown
![لوگوی گیت‌هاب](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png)
```

**خروجی:**
![لوگوی گیت‌هاب](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png)

## بخش چهارم: کدهای برنامه‌نویسی و جداکننده

### نمایش کد (Code)

برای نمایش یک قطعه کد کوتاه در وسط متن، اون رو بین دو بک‌تیک (`` ` ``) قرار بده.

```markdown
در پایتون، برای چاپ کردن یک متن از تابع `print()` استفاده می‌کنیم.
```

**خروجی:**
در پایتون، برای چاپ کردن یک متن از تابع `print()` استفاده می‌کنیم.

برای نمایش یک بلوک کامل از کد، اون رو بین سه بک‌تیک (```` ``` ````) قرار بده. می‌تونی زبان کد رو هم مشخص کنی تا رنگی و خواناتر بشه (Syntax Highlighting).


def say_hello(name):
  print(f"Hello, {name}!")

say_hello("World")


**خروجی:**
```python
def say_hello(name):
  print(f"Hello, {name}!")

say_hello("World")
```

### خط افقی (Horizontal Rule)

برای جدا کردن بخش‌های مختلف متن، می‌تونی از سه یا بیشتر خط تیره `---`، ستاره `***` یا زیرخط `___` در یک خط جداگانه استفاده کنی.

```markdown
این یک بخش از متن است.
***
و این یک بخش دیگر.
```

**خروجی:**
این یک بخش از متن است.
***
و این یک بخش دیگر.

## بخش پنجم: قابلیت‌های پیشرفته (عالی برای مقالات)

### جدول‌ها (Tables)

ساختن جدول شاید اولش کمی سخت به نظر بیاد، ولی خیلی کاربردیه. ستون‌ها رو با `|` و سربرگ (header) رو با `---` جدا کن.

```markdown
| سرتیتر ۱ | سرتیتر ۲ | سرتیتر ۳ |
| :--- | :---: | ---: |
| متن ستون ۱ | متن ستون ۲ | متن ستون ۳ |
| ردیف دوم | وسط‌چین | راست‌چین |
| ردیف سوم | این هم وسط‌چینه | `123` |
```
**توضیح:**
- استفاده از `:` در خط `---` به ترتیب برای چپ‌چین، وسط‌چین و راست‌چین کردن ستون‌هاست.

**خروجی:**
| سرتیتر ۱ | سرتیتر ۲ | سرتیتر ۳ |
| :--- | :---: | ---: |
| متن ستون ۱ | متن ستون ۲ | متن ستون ۳ |
| ردیف دوم | وسط‌چین | راست‌چین |
| ردیف سوم | این هم وسط‌چینه | `123` |

### لیست وظایف (Task Lists)

این قابلیت در گیت‌هاب خیلی محبوبه و برای مشخص کردن کارها عالیه.

```markdown
- [x] آموزش بخش‌های اولیه
- [x] نوشتن در مورد لیست‌ها و لینک‌ها
- [ ] اضافه کردن بخش جدول‌ها
- [ ] نوشتن یک مثال جامع
```

**خروجی:**
- [x] آموزش بخش‌های اولیه
- [x] نوشتن در مورد لیست‌ها و لینک‌ها
- [ ] اضافه کردن بخش جدول‌ها
- [ ] نوشتن یک مثال جامع

### پانویس (Footnotes)

برای مقالات علمی و ارجاع دادن خیلی به درد می‌خوره.

```markdown
این یک متن است که نیاز به یک پانویس دارد.[^1] و این هم یک متن دیگر با پانویس دوم.[^footnote2]

[^1]: این توضیحات پانویس اول است.
[^footnote2]: توضیحات پانویس دوم اینجا قرار می‌گیرد.
```

**خروجی:**
این یک متن است که نیاز به یک پانویس دارد.[^1] و این هم یک متن دیگر با پانویس دوم.[^footnote2]

[^1]: این توضیحات پانویس اول است.
[^footnote2]: توضیحات پانویس دوم اینجا قرار می‌گیرد.

### کاراکترهای گریز (Escaping Characters)

اگه بخوای از کاراکترهایی که در مارک‌داون معنی خاصی دارن (مثل `*` یا `#`) به شکل عادی استفاده کنی، کافیه قبلشون یک بک‌اسلش `\` بذاری.

```markdown
می‌خوام خود ستاره رو نمایش بدم، نه متن کج: \*این متن کج نیست\*
```

**خروجی:**
می‌خوام خود ستاره رو نمایش بدم، نه متن کج: \*این متن کج نیست\*

## فهرست مطالب (Table of Contents)

این فهرست به شما کمک می‌کنه تا به سرعت به بخش مورد نظر خودتون در این راهنما بپرید. خود این فهرست هم یک مثال عالی برای یادگیری یکی از قابلیت‌های مهم مارک‌داون، یعنی **لینک‌دهی داخلی** است.

**چطور این فهرست کار می‌کنه؟**

1.  وقتی شما با استفاده از `#` یک سرتیتر می‌سازید، پلتفرم‌هایی مثل گیت‌هاب به طور خودکار یک `id` منحصر به فرد برای اون سرتیتر ایجاد می‌کنن.
2.  این `id` معمولاً با تبدیل متن سرتیتر به حروف کوچک و جایگزین کردن فاصله‌ها با خط تیره (`-`) ساخته می‌شه. برای مثال، سرتیتر `## بخش اول: اصول اولیه` به `id` با نام `بخش-اول-اصول-اولیه` تبدیل می‌شه.
3.  حالا شما می‌تونید با استفاده از فرمت لینک مارک‌داون، به این `id` لینک بدید: `[متن دلخواه شما](#id-ساخته-شده)`.

در فهرست زیر، از لیست‌های تودرتو برای نمایش بهتر ساختار مقاله استفاده شده.

## بخش ششم: ترفندهای پیشرفته و حرفه‌ای

حالا که با اصول اولیه و پیشرفته آشنا شدی، وقتشه چندتا ترفند یاد بگیری که نوشته‌هات رو از بقیه متمایز کنه. این قابلیت‌ها ممکنه در همه پلتفرم‌ها (به خصوص نسخه‌های قدیمی‌تر مارک‌داون) پشتیبانی نشن، ولی در جاهایی مثل گیت‌هاب (GFM - GitHub Flavored Markdown) به خوبی کار می‌کنن.

### ترکیب HTML و Markdown

یکی از قدرتمندترین ویژگی‌های مارک‌داون اینه که می‌تونی کدهای HTML رو مستقیماً داخلش بنویسی. این بهت انعطاف‌پذیری بی‌نهایتی می‌ده.

#### تغییر رنگ و استایل متن

می‌تونی از تگ `<font>` یا `<span>` برای تغییر رنگ متن استفاده کنی.

```html
این یک متن <font color="red">قرمز</font> است.
```

**خروجی:**
این یک متن <font color="red">قرمز</font> است.

#### وسط‌چین کردن متن یا عناصر

```html
<div align="center">
این متن یا تصویر در وسط قرار می‌گیرد.
</div>
```

**خروجی:**
<div align="center">
این متن یا تصویر در وسط قرار می‌گیرد.
</div>

#### ساخت منوهای بازشونده (Collapsible Sections)

این قابلیت برای پنهان کردن محتوای طولانی و مرتب نگه‌داشتن صفحه عالیه.

```html
<details>
<summary>برای دیدن جزئیات اینجا کلیک کنید</summary>

اینجا می‌تونی کلی متن، کد، تصویر یا هر چیز دیگه‌ای قرار بدی. این محتوا به صورت پیش‌فرض مخفیه و با کلیک روی عنوان، نمایش داده می‌شه.

</details>
```

**خروجی:**
<details>
<summary>برای دیدن جزئیات اینجا کلیک کنید</summary>

اینجا می‌تونی کلی متن، کد، تصویر یا هر چیز دیگه‌ای قرار بدی. این محتوا به صورت پیش‌فرض مخفیه و با کلیک روی عنوان، نمایش داده می‌شه.

</details>

### لینک‌دهی داخلی به سرتیترها (Linking to Heading IDs)

در گیت‌هاب و خیلی از پلتفرم‌های دیگه، هر سرتیتر به طور خودکار یک ID دریافت می‌کنه. این ID معمولاً از روی متن سرتیتر ساخته می‌شه (با حروف کوچک و جایگزینی فاصله‌ها با خط تیره). می‌تونی به این IDها لینک بدی.

```markdown
### یک بخش مهم در مقاله

برای رفتن به [بخش مهم](#یک-بخش-مهم-در-مقاله) کلیک کنید.
```
این کار برای ساختن فهرست مطالب (Table of Contents) در ابتدای مقاله‌های طولانی خیلی کاربردیه.

### نمایش فرمول‌های ریاضی (Math Expressions)

در پلتفرم‌هایی که از MathJax یا KaTeX پشتیبانی می‌کنن (مثل بعضی از نسخه‌های گیت‌هاب و ابزارهای علمی)، می‌تونی فرمول‌های ریاضی رو با فرمت LaTeX بنویسی.

- **فرمول در وسط متن (Inline):** با یک `$` در دو طرف.
- **فرمول در یک بلوک جداگانه (Block):** با دو `$$` در دو طرف.

```markdown
فرمول معروف انرژی اینشتین به صورت $E=mc^2$ نوشته می‌شود.

فرمول کلی معادله درجه دو به این صورت است:
$$ax^2 + bx + c = 0$$
```

**خروجی (در صورت پشتیبانی):**
فرمول معروف انرژی اینشتین به صورت $E=mc^2$ نوشته می‌شود.

فرمول کلی معادله درجه دو به این صورت است:
$$
ax^2 + bx + c = 0
$$

### افزودن ایموجی (Emoji)

در گیت‌هاب و خیلی جاهای دیگه، می‌تونی با نوشتن کد ایموجی بین دو دو نقطه (`:`)، ایموجی به متنت اضافه کنی.

```markdown
نوشتن با مارک‌داون خیلی باحاله! :joy:
```

**خروجی:**
نوشتن با مارک‌داون خیلی باحاله! :joy: :rocket:

## نکات تکمیلی و بهترین شیوه‌ها (Best Practices)

1.  **خوانایی کد مارک‌داون:** همیشه سعی کن خود فایل `.md` هم خوانا باشه. بین بخش‌های مختلف از خط افقی `---` یا چند خط خالی استفاده کن.
2.  **سازگاری:** به یاد داشته باش که مارک‌داون "طعم‌های" مختلفی داره (مثل CommonMark, GFM, Markdown Extra). قابلیت‌های پیشرفته مثل جدول‌ها یا لیست وظایف ممکنه در همه جا یکسان کار نکنن. همیشه بهتره قابلیت‌های اصلی رو در اولویت قرار بدی.
3.  **متن جایگزین برای تصاویر:** همیشه برای تصاویر `alt text` مناسب بنویس. این کار هم به سئو (SEO) کمک می‌کنه و هم باعث می‌شه افرادی که از صفحه‌خوان‌ها (Screen Readers) استفاده می‌کنن، متوجه محتوای تصویر بشن.
4.  **استفاده از ویرایشگر مناسب:** از یک ویرایشگر کد یا متن استفاده کن که از Markdown پشتیبانی می‌کنه و قابلیت پیش‌نمایش زنده (Live Preview) داره. ابزارهایی مثل **VS Code**, **Typora**, **Obsidian** یا حتی ویرایشگر آنلاین گیت‌هاب عالی هستن.

### انقلاب Markup تلگرام

اخیرا پشتیبانی از پیام‌هایی با فرمت Markdown به تلگرام اضافه شده که به ربات‌ها اجازه میده متن‌های کاملا ساختاریافته‌ ارسال کنن. [^3]  
برای مثال پاسخ‌های تولید شده توسط هوش مصنوعی ها رو با قالب‌بندی اصولی، استاندارد، مرتب و خوانا و بدون درهم‌ریختگی جداول و تیترها منتشر کنن  
به احتمال زیاد در آینده نزدیک در دسترس عموم عم قرار می‌گیره، الان علی الحساب می‌تونید متن خودتون رو با مارک‌داون نوشته و به ربلت تلگرامی [@RichTextEchoBot](https://t.me/RichTextEchoBot) خفن بفرستید تا متن شما رو رندر کرده و براتون ارسال کنه، همین‌قدر جذااااب ؛)

## منابع برای یادگیری بیشتر

اینترنت پر از منابع عالی برای یادگیری عمیق‌تر مارک‌داونه. در ادامه چندتا از بهترین‌ها رو معرفی می‌کنم:

### راهنماها و تقلب‌نامه‌ها (Cheatsheets)

این صفحات برای مراجعه سریع و به یادآوری سینتکس عالی هستن.

* **[The Markdown Guide](https://www.markdownguide.org/extended-syntax/)**: کامل‌ترین و بهترین مرجع برای یادگیری مارک‌داون. هم بخش آموزشی داره و هم یک تقلب‌نامه جامع.
* **[Markdown Cheatsheet on GitHub](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet)**: یک تقلب‌نامه خیلی محبوب و کامل که اکثر موارد رو پوشش می‌ده.
* **[Markdown Tutorial by CommonMark](https://commonmark.org/help/)**: یک آموزش تعاملی و خوب برای یادگیری اصول استاندارد مارک‌داون.

### ابزارهای آنلاین

* **[Dillinger](https://dillinger.io/)**: یک ویرایشگر آنلاین مارک‌داون با قابلیت پیش‌نمایش زنده که می‌تونی فایل‌هات رو به فرمت‌های مختلف مثل HTML و PDF خروجی بگیری.
* **[StackEdit](https://stackedit.io/)**: یک ویرایشگر آنلاین قدرتمند دیگه که با سرویس‌هایی مثل Google Drive و Dropbox همگام‌سازی می‌شه.
* **[Markdown Tables Generator](https://www.tablesgenerator.com/markdown_tables)**: ساختن جدول‌های پیچیده با دست می‌تونه خسته‌کننده باشه. این ابزار بهت اجازه می‌ده جدول رو به صورت گرافیکی بسازی و کد مارک‌داونش رو تحویل بگیری.
