آموزش کامل Markdown ​

از صفر تا صد برای نوشتن مقالات ​

سلام! این راهنما برای این نوشته شده که تو بتونی به راحتی هر نوع متنی، از یک یادداشت ساده گرفته تا یک مقاله کامل رو با استفاده از Markdown بنویسی. Markdown یک زبان نشانه‌گذاری خیلی ساده‌ست که بهت اجازه می‌ده بدون نیاز به نرم‌افزارهای پیچیده مثل Word، متن‌های زیبا و ساختاریافته بنویسی.

مزیت بزرگش اینه که خیلی راحت به فرمت‌های دیگه مثل HTML تبدیل می‌شه و پلتفرم‌هایی مثل گیت‌هاب، وبلاگ‌ها و خیلی از ابزارهای دیگه ازش پشتیبانی می‌کنن.

بزن بریم شروع کنیم!

| ردیف دوم | وسط‌چین | راست‌چین |

فهرست مطالب (Table of Contents) ​

این فهرست به شما کمک می‌کنه تا به سرعت به بخش مورد نظر خودتون در این راهنما بپرید. خود این فهرست هم یک مثال عالی برای یادگیری یکی از قابلیت‌های مهم مارک‌داون، یعنی لینک‌دهی داخلی است.

چطور این فهرست کار می‌کنه؟

  1. وقتی شما با استفاده از # یک سرتیتر می‌سازید، پلتفرم‌هایی مثل گیت‌هاب به طور خودکار یک id منحصر به فرد برای اون سرتیتر ایجاد می‌کنن.
  2. این id معمولاً با تبدیل متن سرتیتر به حروف کوچک و جایگزین کردن فاصله‌ها با خط تیره (-) ساخته می‌شه. برای مثال، سرتیتر ## بخش اول: اصول اولیه به id با نام بخش-اول-اصول-اولیه تبدیل می‌شه.
  3. حالا شما می‌تونید با استفاده از فرمت لینک مارک‌داون، به این id لینک بدید: [متن دلخواه شما](#id-ساخته-شده).

در فهرست زیر، از لیست‌های تودرتو برای نمایش بهتر ساختار مقاله استفاده شده.

حتما! با کمال میل ادامه میدم و بخش پیشرفته، نکات تکمیلی و منابع بیشتر رو به راهنمای قبلی اضافه می‌کنم. این هم از ادامه راهنما با همون فرمت مارک‌داون:

بخش ششم: ترفندهای پیشرفته و حرفه‌ای ​

حالا که با اصول اولیه و پیشرفته آشنا شدی، وقتشه چندتا ترفند یاد بگیری که نوشته‌هات رو از بقیه متمایز کنه. این قابلیت‌ها ممکنه در همه پلتفرم‌ها (به خصوص نسخه‌های قدیمی‌تر مارک‌داون) پشتیبانی نشن، ولی در جاهایی مثل گیت‌هاب (GFM - GitHub Flavored Markdown) به خوبی کار می‌کنن.

ترکیب HTML و Markdown ​

یکی از قدرتمندترین ویژگی‌های مارک‌داون اینه که می‌تونی کدهای HTML رو مستقیماً داخلش بنویسی. این بهت انعطاف‌پذیری بی‌نهایتی می‌ده.

در گیت‌هاب و خیلی از پلتفرم‌های دیگه، هر سرتیتر به طور خودکار یک ID دریافت می‌کنه. این ID معمولاً از روی متن سرتیتر ساخته می‌شه (با حروف کوچک و جایگزینی فاصله‌ها با خط تیره). می‌تونی به این IDها لینک بدی.

  • فرمول در یک بلوک جداگانه (Block): با دو $$ در دو طرف.

نکات تکمیلی و بهترین شیوه‌ها (Best Practices) ​

  1. خوانایی کد مارک‌داون: همیشه سعی کن خود فایل .md هم خوانا باشه. بین بخش‌های مختلف از خط افقی --- یا چند خط خالی استفاده کن.
  2. سازگاری: به یاد داشته باش که مارک‌داون "طعم‌های" مختلفی داره (مثل CommonMark, GFM, Markdown Extra). قابلیت‌های پیشرفته مثل جدول‌ها یا لیست وظایف ممکنه در همه جا یکسان کار نکنن. همیشه بهتره قابلیت‌های اصلی رو در اولویت قرار بدی.
  3. متن جایگزین برای تصاویر: همیشه برای تصاویر alt text مناسب بنویس. این کار هم به سئو (SEO) کمک می‌کنه و هم باعث می‌شه افرادی که از صفحه‌خوان‌ها (Screen Readers) استفاده می‌کنن، متوجه محتوای تصویر بشن.
  4. استفاده از ویرایشگر مناسب: از یک ویرایشگر کد یا متن استفاده کن که از Markdown پشتیبانی می‌کنه و قابلیت پیش‌نمایش زنده (Live Preview) داره. ابزارهایی مثل VS Code, Typora, Obsidian یا حتی ویرایشگر آنلاین گیت‌هاب عالی هستن.

اینترنت پر از منابع عالی برای یادگیری عمیق‌تر مارک‌داونه. در ادامه چندتا از بهترین‌ها رو معرفی می‌کنم:

راهنماها و تقلب‌نامه‌ها (Cheatsheets) ​

این صفحات برای مراجعه سریع و به یادآوری سینتکس عالی هستن.

  • The Markdown Guide: کامل‌ترین و بهترین مرجع برای یادگیری مارک‌داون. هم بخش آموزشی داره و هم یک تقلب‌نامه جامع.
  • Markdown Cheatsheet on GitHub: یک تقلب‌نامه خیلی محبوب و کامل که اکثر موارد رو پوشش می‌ده.
  • Markdown Tutorial by CommonMark: یک آموزش تعاملی و خوب برای یادگیری اصول استاندارد مارک‌داون.

ابزارهای آنلاین ​

  • Dillinger: یک ویرایشگر آنلاین مارک‌داون با قابلیت پیش‌نمایش زنده که می‌تونی فایل‌هات رو به فرمت‌های مختلف مثل HTML و PDF خروجی بگیری.
  • StackEdit: یک ویرایشگر آنلاین قدرتمند دیگه که با سرویس‌هایی مثل Google Drive و Dropbox همگام‌سازی می‌شه.
  • Markdown Tables Generator: ساختن جدول‌های پیچیده با دست می‌تونه خسته‌کننده باشه. این ابزار بهت اجازه می‌ده جدول رو به صورت گرافیکی بسازی و کد مارک‌داونش رو تحویل بگیری.
